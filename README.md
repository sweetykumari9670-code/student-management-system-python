# 🎓 Student Management System Using Python

A console-based student management application built using Python to manage student records and academic performance.

## 📌 About the Project

The Student Management System helps users maintain student information through a simple menu-driven interface. It supports adding, viewing, searching, updating, and deleting student records.

Student information is stored locally in a JSON file, allowing records to remain available between program runs.

## ✨ Features

- Add new student records
- View all registered students
- Search students by ID or name
- Update student information
- Delete records with confirmation
- Calculate grades based on marks
- View academic statistics
- Calculate average, highest, and lowest marks
- Count students scoring 40 or above
- Store records in a JSON file
- Validate user input

## 🛠️ Technologies Used

- Python 3
- JSON for data storage
- File handling
- Lists and dictionaries
- Functions and conditional statements
- Exception handling

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/sweetykumari9670-code/student-management-system-python.git
```

### 2. Open the project folder

```bash
cd student-management-system-python
```

### 3. Run the application

```bash
python3 student_management.py
```

## 💻 How to Use

1. Start the program.
2. Choose an option from the main menu.
3. Add student details such as ID, name, age, course, and marks.
4. View or search for student records.
5. Update or delete records when required.
6. Use the statistics option to review academic performance.
7. Select Exit to close the application.
